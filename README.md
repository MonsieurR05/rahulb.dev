# rahulb.dev

Personal portfolio for Rahul Bagga: a dark, minimal, monochrome site built to be quick to scan.

## Features
- Hero with a `profile.json` code card
- Project cards with case-study dialogs (problem, solution, features, outcome)
- About grid: focus areas, live London time, degree timeline, toolkit
- Experience timeline
- Command menu (⌘K / Ctrl K) to jump to sections, open projects and copy contact details
- Scroll-reveal motion that respects reduced-motion settings
- Responsive layout from phone to desktop

## Content
All portfolio text lives in `src/data/portfolio.js`.

## Tech Stack
Next.js, React, JavaScript, Tailwind CSS

## Development
`npm install` then `npm run dev`
